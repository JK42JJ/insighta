# §9-2 희소성 프롬프트 A/B/B′/C 평가 (핸드오프 원문, 2026-09-16 갱신)

## 본질

현재 S4 요약(A), 원문 프롬프트만 쓴 B, 스모크에서 쓴 CC 문장 B′, 원문 프롬프트 + 이웃 10편 주장 목록을 붙인 C를 같은 27편에 돌려 비교한다. 결론은 사람 블라인드 평가가 낸다. 기계 지표는 보조.

## 프롬프트 (한 글자도 바꾸지 않는다)

- B: 다른 유튜브에서 얘기하지 않는 가장 중요한 내용을 발췌해 줘
- B′: "다른 영상이 말하지 않는 이 영상만의 주장 1개(unique_claim, 근거 타임스탬프)" — 스모크 문장, 비교용
- C: B 문장 그대로 + 줄바꿈 + "참고: 같은 주제 영상 10편에서 나온 주장 목록" + 이웃 주장 목록
- A: 현재 프로덕션 S4 프롬프트, 같은 모델·같은 날 재생성. 기존 저장 요약은 A0로 참고만.

## 이웃 정의

cluster_key가 있으면 같은 키의 영상 10편. 없으면 BGE-M3 임베딩 상위 10편. 이웃 목록이 주장 형태로 없으면 이웃의 기존 요약을 그대로 붙이고 그 형태를 원장에 적는다. k=10 고정.

1. 평가 원장: video_id, arm, 프롬프트 전문, 발췌 주장(들), 근거 타임스탬프, 이웃 k, 토큰, 지연, 기계 근거율, 기계 축어 일치, ts 오차, 기계 희소성.
2. 블라인드 시트: 27행 × (A/B/B′/C 무작위 순서, 라벨 숨김). James가 "브리프 리드로 쓸 한 줄" 하나를 고르는 칸 + 메모 칸. 라벨 복호 키는 별도 파일.

4. 결과 보고: 여섯 지표 표 + 판정선 대비 통과/기각.

## 지표와 판정선 (사전 고정, 사후 조정 금지)

- 선호 승률: B 또는 C가 A 대비 18/27 이상(단측 p≈0.04).
- 근거율(발췌 주장이 원 영상 자막·구간에 있는가): A 대비 −5%p 이내.
- 축어 일치율(발췌문이 자막에 실제 있는 연속 문자열인가, 12자 한글/24자 라틴 ±60초 = #1662 게이트 기준): 별도 보고.
- 희소 정확도("다른 데서 안 한다"고 뽑은 주장이 실제 이웃 10편에 없는 비율): 70% 이상.
- 브리프 중복률(27편 발췌를 5항목으로 묶었을 때 항목 간 겹침): A 미만.
- 비용·지연: C가 A의 3배 초과 시 보고.
- 셋(선호·근거·희소) 통과 시 리드 승격 후보. 선호는 이기는데 근거율이 떨어지면 "타임스탬프 필수" 제약을 넣어 1회 재시험.
