## 프루닝 규칙

- 주 1회 리뷰에서 삭제 수 ≥ 추가 수. 삭제 후보 = 집행 장치 "없음" 이고 지난 4주 재발 0 인 규칙.
- 모델 교체 시 "금지 사항" 류(R13 · R15 · R16 · R18 · R19) 부터 재검토한다.
- 새 규칙은 사고 1회로 만들지 않는다. 같은 사고 2회 + 집행 장치 설계가 있을 때만.
