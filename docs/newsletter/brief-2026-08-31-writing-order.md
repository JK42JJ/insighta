# 집필 의뢰 — AI 엔지니어링 주간 브리프 제1호

동봉: `material-2026-08-31.md` (근거 274편, 46KB)

## 무엇을 쓰는가

**기술 에세이 한 편.** 이번 주 AI 엔지니어링에서 실제로 무슨 일이 있었고, 그것이
현업 엔지니어의 다음 주 작업에 무엇을 바꾸는지.

## 무엇을 쓰지 않는가

**우리가 어떻게 골랐는지는 본문이 아닙니다.**

첫 시도가 여기서 실패했습니다. "814편 수집 → 372편이 4분 미만이라 탈락 → 116편이
행동할 것 없어 탈락" 을 1면 표로 올렸습니다. 독자는 우리 필터링 통계를 구독한 것이
아니라 AI 엔지니어링을 구독했습니다. 수집·선별 수치는 **맨 끝 방법 주석 3~4줄**이
전부입니다. 본문·헤드라인·표에 등장하면 실패입니다.

## 재료에서 보이는 것 (참고, 강제 아님)

에세이의 축은 집필자가 정합니다. 다만 재료를 읽으면 한 줄기가 두드러집니다 —
**에이전트가 권한을 갖기 시작하면서 텍스트가 실행이 됐다**는 것.

- Checkpoint 가 Claude Code 에서 찾은 공급망 취약점: 부팅 시 `settings.json` 을
  검증하지 않아, 함정을 심은 저장소를 여는 것만으로 임의 명령 실행 (`1IbrFrdll4U`)
- 웹페이지 요약을 시켰을 뿐인데 간접 인젝션이 Auto Mode 를 원격 코드 실행까지
  끌고 가는 실연 (`Dsx4_kCBkbQ`)
- PayPal 이 순서를 뒤집은 승인 토큰 — 에이전트가 상품과 판매자를 고르기 **전에**
  사용자가 승인 (`vGn6N4-bxBY`)
- 지원 봇을 만들어 다섯 방식으로 깨뜨리는 실연 — 권한 없는 환불 승인, 보호하라고
  지시받은 내부 코드 유출 (`QSCIYtTSe6A`)

반대편에는 값을 직접 재는 사람들이 있습니다 — 8GB 부터 32GB 까지 같은 모델을
돌려 보고 (`0xUxO_9zqTU`), 월 $200 구독과 $5,000 장비의 손익분기를 계산하고
(`psNfWOOtBGM`), 모든 에이전트 하네스가 JSON 에서 물려받은 설계 실수를 짚습니다
(`nIBJy3sNu9A`).

축을 다르게 잡아도 됩니다. 재료 안에 있으면 됩니다.

## 규칙

1. **재료에 없는 사실은 쓰지 않습니다.** 외부 수치·날짜·가격을 기억으로 채우지
   마세요. 확인되지 않은 것은 "여러 채널이 그렇게 말하고 있다" 로 쓰거나 뺍니다.
2. **주장에는 출처를 답니다.** videoId 를 적어 주시면 링크는 저희가 만듭니다.
3. **AI 말투를 지웁니다.** "~하는 것이 중요합니다", "살펴보겠습니다", "결론적으로",
   불필요한 "~적", 습관적 "매우". 사람이 쓴 기술 산문이어야 합니다.
4. **길이**: 읽는 데 6~8분. 이야기 3~4개.
5. **독자**: 에이전트를 만들거나 붙이고 있는 실무 엔지니어. 입문자가 아닙니다.

## 넘겨받을 형태

산문으로 주시면 됩니다. 아래만 구분해 주세요.

```
헤드라인 (2줄로 끊어서)
데크 (2~3문장)
—
이야기 1 ~ 4:  꼭지말 / 제목 / 본문
—
이번 주 한 문장 + 실무자가 할 일 3~4개 (오늘/이번 주/이번 달)
—
용어 3~5개: 단어 / 영문 / 설명 / 실제 대화 예문
—
추천 영상 5편에 붙일 각 3~4문장 (videoId 지정)
—
메일 요약: 5줄 (제목 + 한 문장). 본문 요약이 아니라, 무엇이 더는
사실이 아니게 됐는지를 말하는 줄.
```

스키마 조립·링크 검증·발행 게이트는 저희가 합니다.
