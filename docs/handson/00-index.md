# 인프라 핸즈온

James 가 직접 치고, CC 가 판정한다.

교재는 가상의 예제가 아니라 **2026-09-03 하루에 실제로 터진 사건들**이다. 그날
브리프 기능 하나를 배포하는 데 배포가 세 번 막혔고, 마이그레이션 하나가
프로드에 없었고, API 다섯 개가 조용히 401 을 돌려주고 있었다. 각 사건이 한
트랙의 실습이 된다.

## 진행 방식

각 실습은 **명령 → 예상 → 실제 → 판정** 네 칸이다.

James 가 명령을 치기 **전에** 무엇이 나올지 한 줄로 적는다. 그 다음 친다.
예상과 실제가 다르면 그 자리가 배울 곳이다. CC 가 왜 다른지 답한다.

예상을 적지 않고 치면 실습이 아니라 구경이다. 그 한 줄이 이 문서의 전부다.

## 안전 규칙

| | |
|---|---|
| 읽기 전용 | `kubectl get/logs/describe`, `terraform plan`, `git log`, `curl` |
| 되돌릴 수 있음 | 코드 수정 → PR → 머지 → 배포 → `git revert` |
| **하지 않는다** | `terraform apply`, prod DB 쓰기, 데몬 재시작, 시크릿 회전 |

마지막 줄은 실습에서 제외한다. 되돌리는 데 다른 사람의 시간이 들거나,
되돌릴 수 없기 때문이다. 그 셋은 CC 가 하는 것을 James 가 보는 형태로 한다.

## 트랙

| | 트랙 | 실습으로 만드는 사건 |
|---|---|---|
| 01 | [배포 체인](01-deploy-chain.md) | 배포 success 인데 프로드에 안 닿음 (하루 3회) |
| 02 | k8s — 지금 도는 코드 확정 | 어제 이미지가 돌고 있었는데 아무도 몰랐음 |
| 03 | helm — 이미지 핀과 롤백 | `prod.yaml` 두 줄이 무엇을 정하는가 |
| 04 | ArgoCD — 수동 동기화 | `Synced` 인데 옛 커밋이었음 |
| 05 | GitHub Actions | `GITHUB_TOKEN` 이 민 브랜치는 체크가 안 돈다 |
| 06 | DB / prisma | `db push` 가 테이블을 드롭하려 함 · 마이그레이션 미적용 |
| 07 | terraform (읽기 전용) | drift 가 EIP 를 되돌릴 뻔함 |
| 08 | ansible / SSH | `~/.ssh/config` 옛 IP 로 엉뚱한 노드 접속 |

01 부터 시작한다. 나머지는 01 이 끝난 뒤 순서를 다시 정한다 — 01 을 하면
02~05 의 절반은 이미 손에 익는다.
