# 큐레이션 주간 편성 복구 · 유해 주제 차단 · 다이얼 시트 재설계 (2026-07-27)

## 한눈에 보기

- **주간 큐레이션이 실제로 매주 갱신됩니다.** 지금까지 한 번도 자동 갱신된 적이 없었습니다.
- **부적절한 추천 주제가 사라졌습니다.** 학습 플랫폼에 나올 수 없는 주제가 추천 1순위에 올라와 있었습니다.
- **주간 큐레이션을 누르면 즉시 반응합니다.** 5초 동안 아무 일도 없다가 갑자기 넘어가던 것을 고쳤습니다.
- **추천 주제를 옆으로 넘겨 고릅니다.** 세로로 쌓여 잘리던 카드가 가로 덱이 되었습니다.
- **어드민에서 초대 메일이 실제로 나갔는지 보입니다.**

## 왜 바꿨나

### 주간 편성이 한 번도 안 왔습니다

7월 26일 일요일 밤, 갱신 작업은 정상적으로 실행됐고 **0건을 만들고 끝났습니다.**

```
curation-weekly  2026-07-26 23:17:03 → 완료 (92ms)
새로 만들어진 편성  0건
```

원인은 **시계가 두 개인데 서로 맞지 않았던 것**입니다. 갱신 검사는 일주일에 한 번(일요일 밤)만 도는데, 각 구독이 "갱신할 때가 됐다"고 판단하는 시각은 그 구독이 마지막으로 만들어진 시각 + 7일이었습니다. 그 시각이 검사 시점을 조금이라도 지나면 **다음 주까지 기다립니다.** 실제 주기가 7일이 아니라 8~14일이었습니다.

두 번째 문제는 더 조용했습니다. 주차를 계산하는 코드가 세계시 기준이라, **월요일 아침(한국시간)에 만들어지는 편성이 지난주 칸에 덮어써지게** 되어 있었습니다. 첫 번째만 고쳤으면 매주 지난주 편성이 지워지고 "이번 주 완청" 표시까지 이월됐을 겁니다.

이제 갱신 판단에서 시각 계산을 없애고 **한국 시간 요일**만 봅니다. 요일을 무엇으로 고르든 정확히 주 1회입니다.

### 추천에 부적절한 주제가 올라와 있었습니다

추천 후보는 유튜브 자동완성에서 긁어옵니다. **아무 필터도 없었습니다.** 게다가 순위 기준이 순수 인기도라, 자극적인 검색어가 자동으로 1등이 됐습니다.

수집과 표시 두 지점에서 막고, 이미 쌓여 있던 것도 정리했습니다. 다만 **단어 목록만으로는 절반의 문제밖에 못 풉니다** — 실제로 확인해 보니 추천 후보의 상당수가 유해하진 않지만 애초에 학습 주제가 아니었습니다(가수 이름, 동네 이름, 캐럴 제목, 교회 이름). 그래서 **AI 가 "안전한가"와 "배울 만한 주제인가"를 함께 판정**하도록 바꾸는 작업을 이어서 진행 중입니다.

### 트렌드 수집이 7주간 멈춰 있었습니다

6월 4일 이후 새 데이터가 들어오지 않았습니다. 고장이 아니라, **비용이 큰 다른 작업과 한 파일에 묶여 있어서 그것을 끄면서 같이 꺼진 것**이었습니다. 확인해 보니 트렌드 수집 자체의 비용은 하루 10유닛(전체 한도의 0.0125%)이었습니다. 따로 떼어 다시 켰고, 7주 만에 새 데이터가 들어왔습니다.

## 알려진 한계 · 다음

- **AI 주제 판정은 배포됐지만 백필 전입니다.** 19,129건이 아직 미판정이라, 새로 수집되는 것부터 걸러지고 기존 축적분은 백필 후 적용됩니다.
- **영상 메뉴에 큐레이션 붙이기**(핵심/전체 재생 + 관련도 표현)는 설계와 목업까지 완료, 구현 전입니다.
- **채널 직접 등록**(내가 고른 채널만 매주 받기)은 서버가 전부 완성됐고 **화면만 남았습니다.** 화면은 실기기 검토 게이트라 대기 중이며, 기능 플래그가 꺼져 있어 지금은 동작 변화가 없습니다.
- 다이얼 화면 변경은 **실기기 검증 전**입니다.
