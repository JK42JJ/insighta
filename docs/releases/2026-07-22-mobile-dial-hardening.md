# 2026-07-22 — 모바일 다이얼: 조그휠 고스트음·가로 정렬·슬라이더가 손에 맞습니다

> **세션 별칭: `모바일-다이얼-하드닝`**

## 한눈에 보기

모바일 다이얼(iPod 폼팩터 플레이어)의 온디바이스 버그 묶음을 감독관 검수와 함께 정리했습니다. 조그휠로 넘길 때 **이전 영상이 백그라운드로 계속 재생되던 고스트음**을 없앴고, **가로 모드에서 영상이 좌우로 쏠리던 현상**과 **홈 목록이 저 혼자 위아래로 출렁이던 진동**을 잡았습니다. 하단 **슬라이더는 카드 아래 가장자리에 정확히 얹혀** 큐레이션↔노트 탭 중앙만 오가도록 폭을 좁혀, 엄지 하나로 다루기 편해졌습니다. 앱 버전이 바뀌면 **자동 업데이트 토스트**가 떠서 한 번 탭으로 최신본이 적용됩니다.

## 사용자 관점 변경점

- **조그휠 고스트음 제거**: 휠로 다음/이전 영상으로 넘기면 이전 영상 오디오가 즉시 멈춥니다 (단일 오디오 소유 불변식 — 모든 슬롯 정지 후 활성 슬롯만 재생).
- **가로 모드 정렬**: 영상이 화면에 꽉 차게 중앙 정렬됩니다 (세로에서 만든 iframe 픽셀 크기가 회전 후에도 남아 좌우로 쏠리던 문제 수정).
- **홈 목록 진동 제거**: 사용자가 손대지 않는 동안 목록이 스스로 튀지 않습니다 (백그라운드 갱신이 스크롤/포커스를 건드리지 않는 불변식).
- **연결 해지 화면 가독성**: 확인 버튼 글씨가 보이도록 대비 수정, 문구도 정리.
- **슬라이더 위치·폭**: 썸이 카드 바깥 하단 가장자리에 구슬처럼 얹히고, 이동 범위가 큐레이션 탭 중앙 → 노트 탭 중앙으로 좁혀졌습니다 (엄지 조작).
- **자동 업데이트 토스트**: 새 버전 배포 시 앱에 안내 토스트 — 탭하면 캐시를 비우고 최신본으로 갱신 (홈 화면 설치 앱은 주소창이 없어 수동 하드리로드가 불가능했음).

## 왜 바꿨나 (측정 근거)

- 고스트음: 휠 내비게이션이 이전 슬롯의 `pauseVideo()`를 호출하지 않아 두 플레이어가 동시 재생 — 스와이프 경로만 정지하고 휠 경로는 누락.
- 가로 쏠림: 진범은 iframe이 아니라 **홈 목록의 자율 재렌더 루프**(폴링이 스크롤 앵커를 흔듦) — 감독관의 정량 영상 분석(무조작 상태 ±106~144px, 0.5~1s 주기 교대 점프)으로 방향 교정. iframe은 별건으로 회전 후 포트레이트 픽셀 크기 잔존이 원인.
- 슬라이더: 6라운드 실패의 진짜 원인은 좌표가 아니라 **DOM 구조** — `.epaper{overflow:hidden}`이 카드 밖으로 나온 썸의 절반을 잘라 썸이 영원히 카드 안쪽에 갇혀 있었음(감독관 최종 진단 = 감독관 자신의 계약서가 카드 안쪽 선을 지정한 오류). 썸을 카드의 형제로 빼서 해결.
- 검증: 라이브 로그인 사이트에서 썸 중심 y == 카드 하단 가장자리 y (오차 0px), 3개 정지점 모두 탭 중심과 오차 0px.

### 핵심 구현

- **슬라이더 구조 감옥 해소**: 썸을 overflow 클립 컨테이너(`.hstrip-clip`/`.epaper`) 밖으로 이동. `.device`(flex column, no gap) 직계 자식 + `height:0` → 썸 상단이 카드 하단 가장자리와 픽셀 일치, `.device`는 overflow 제약 없어 절반-밖 썸이 안 잘림. 트랙 인셋 24px = 카드 모서리 반경(직선 구간만 주행).
- **탭 중앙 정렬 이동폭**: `syncSliderToTabs()`가 런타임에 첫/마지막 탭(`.htab`) 중심을 측정해 트랙 box를 정렬(반응형). 레이아웃 변경 시(`animate=true`)에만 재동기화, 드래그 프레임마다 재측정 안 함.
- **홈 전용/세로 전용**: `show()`에서 홈 활성일 때만 `visibility:visible`, `@media (orientation:landscape)`에서 `display:none`.

### 검증 방법 (교훈)

- `resize_window`가 이 환경에서 뷰포트를 안 바꾸는 무효 동작임을 **precondition assert**(측정 전 `window.innerWidth`/`matchMedia` 재확인)로 검출 → 세로=column 레이아웃을 강제 주입해 포트레이트 지오메트리를 충실히 재현 후 측정.
- 트랜지션(`transition:left`) 있는 썸은 `animate=false`(instant)로 최종 위치 측정 (동기 측정 시 트랜지션 시작 전 값을 읽는 아티팩트 회피).
