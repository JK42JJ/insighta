# 다이얼 — 조그휠·클립 재생·새소식 배너 (2026-07-16)

## 한눈에 보기

모바일 '다이얼'을 실기기에서 돌려보며 나온 문제를 16개로 나눠 고쳤습니다. 크게 세 덩어리입니다.

- **조그휠이 하나의 일관된 물건이 되었습니다.** 돌리는 속도에 비례해 빨라지고, 정밀하게 맞추고 싶으면 길게 눌러 미세 모드로 전환합니다. 이동 중에는 재생이 잠깐 멈췄다가 손을 떼면 이어집니다.
- **클립이 소리 없이 재생되던 문제가 사라졌습니다.** 잠깐 멈췄다 다시 틀면 소리가 죽던 증상, 그리고 노트에서 클립으로 자동 전환될 때 iOS가 재생을 막던 증상 둘 다 근본 원인을 찾아 고쳤습니다.
- **클립을 기다리는 동안 검은 화면 대신 썸네일이 보입니다.** 어느 방향으로 넘어가는지도 미리 보여줍니다.

여기에 **새소식 배너**(클로즈드 베타 안내 / 다이얼 출시)가 붙었고, 공유 설정을 휠로 넘길 수 있게 되었습니다.

## 왜 바꿨나

James의 실기기 테스트 리포트가 유일한 근거였습니다. 데스크톱 브라우저는 음소거 자동재생을 허용해서 iOS에서만 나는 증상을 재현할 수 없었고, 그래서 "고쳤다"는 판단은 전부 실기기 확인을 기다렸습니다.

## 알려진 한계 · 백로그

- **조그휠은 미완결입니다.** James 평가 "뻐그 아직 많아". 감도·가속 곡선 등 **튜닝 상수는 전부 추정값**이며 실기기 검증을 통과하지 않았습니다. admin 또는 URL 파라미터로 노출해 실측 튜닝하는 안을 제안해 둔 상태입니다.
- 클립 로딩의 실제 버퍼 타이밍은 실기기 확인 대기.
- 정지 중 내레이션 스크럽 = 백로그.
