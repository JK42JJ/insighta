## 한눈에 보기

이번 릴리즈의 중심은 **"검색이 드디어 진짜로 동작한다"** 입니다. 지금까지 카드 검색은
사용자가 가진 카드의 **0.4%만** 뒤지고 있었습니다 — 화면에 빤히 보이는 "수동태" 카드를
검색해도 0건이 나오던 이유입니다. 이제 ⌘K를 누르면 어느 화면에서든 중앙에 검색창이 뜨고,
**카드·만다라·노트·요약을 한 번에** 찾습니다. 결과는 0.1초 안에 나옵니다.

함께, 템플릿 탐색 화면의 **긴 문장들이 짧은 라벨로** 정리됐고(원문은 마우스를 올리면 툴팁으로),
카드 추가 패널에서는 **썸네일에 마우스를 올리면 영상 장면이 미리 넘겨보기**로 보입니다.

## 무엇이 바뀌었나 (사용자 관점)

### 1. ⌘K 전역 검색 — 새 기능
- 어느 화면에서든 **⌘K** (또는 사이드바 검색창 클릭) → 중앙 검색 팔레트.
- **내 카드, 만다라, 노트, 요약(AI)** 을 한 번에 검색. 그룹별로 묶여서 나오고 건수 표시.
- 검색어 없이 열면 **빠른 작업**: 새 만다라 / 템플릿 찾기.
- 카드 결과를 클릭하면 **해당 만다라로 전환 + 그 카드로 스크롤/하이라이트**.
- 요약 결과는 러닝 페이지의 해당 영상으로 바로 이동.
- 기존 사이드바의 옛 검색(카드 0.4%만 뒤지던 것)은 은퇴 — 검색 경험이 하나로 통일.

### 2. 템플릿 탐색 가독성 — 개선
- 카드 하단의 긴 목표 문장 → **짧은 라벨** (원문은 호버 툴팁).
- 미리보기 9×9 그리드의 긴 실행아이템 → 라벨 있으면 짧게, 없으면 원문 + **호버 툴팁으로 전문**.
- 상위 인기 템플릿 99개(792개 섹터)의 실행아이템 라벨을 **직접 생성해 채움** (LLM API 호출 0 — 하드룰 준수).
- 검색 팔레트의 "템플릿 찾기"가 사이드메뉴와 **같은 화면**(/explore)으로 가도록 정합 (버그였음).

### 3. 카드 추가 패널 — 호버 미리보기
- 후보 카드 썸네일에 마우스를 올리면 **영상의 초/중/후반 장면 3컷이 순환** — 유튜브 호버 프리뷰 느낌.
- 의도적으로 **실제 플레이어(iframe)를 쓰지 않음**: 플레이어는 호버당 2~3MB, 이 방식은 50KB 미만.

### 4. 사이드바 만다라 자산 아이콘 (세션 초반, 별건)
- 요약(v2) 진행 상태 = **단색 점** (완료=진함/부분=중간/없음=흐림, 생성 중엔 깜빡임).
- 노트 존재 여부 아이콘 + 커스텀 툴팁. 선택해도 아이콘은 안 변함(데이터 전용).

## 왜 바꿨나 (근본 원인, 측정 기반)

- **검색 0건의 정체**: 구 검색은 `user_local_cards`(수동 추가분)만 ILIKE — James 계정 실측
  **28장 vs 7,587장** (위저드 자동배치 카드는 `user_video_states`에 있어 검색 밖).
  "수동태"로 재현: 구검색 0건 / 실제 카드 7건. → 5개 소스를 통합하는 새 BE 검색으로 해소.
- **실행아이템에 라벨이 없던 이유**: 라벨 생성(merged-gen)이 루트 레벨까지만 만들었음 —
  depth-1 라벨 보유율 prod 실측 **8/17,852 (0.04%)**. 코드가 아니라 데이터 부재.
- **검색이 빠른 이유**: LLM/임베딩 없이 순수 SQL + trigram 인덱스 + 4그룹 병렬 + user 스코프 선행.
  prod 실측 warm **55ms** (worst-case 검색어, 7.5K카드 계정).
