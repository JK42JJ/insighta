# 2026-07-28 — 지식 그래프 화면 전면 교체 (베타 출시)

## 무엇이 좋아졌나

만다라의 "지식 그래프" 보기가 완전히 새로워졌습니다.

- **읽을 수 있는 지도**: 회색 점무더기+글자 벽이었던 화면이, 색으로 묶인 클러스터·타입별 아이콘 디스크(만다라 과녁/섹터 레이어/영상 ▶/개념 전구…)·허브에만 붙는 라벨로 바뀌었습니다. 줌인할수록 아이콘과 라벨이 단계적으로 드러납니다.
- **안정성**: 마우스만 올려도 화면이 떨리고 이따금 통째로 죽던 문제를 근본 원인(호버마다 그래프 재구축→렌더러 파괴/재생성)째 제거했습니다.
- **찾기**: 그래프 안 검색 → 해당 노드로 카메라 비행 → 상세 패널에서 영상 바로 열기.
- **만다라 단위 보기**: 이제 만다라별 서브그래프를 서버가 잘라서 내려줍니다 (최대 4,000노드, 가까운 것 우선).

## 기술 요약

- FE: react-force-graph → **sigma.js v3 (WebGL) + graphology**. sigma 공식 데모 파이프라인 1:1 이식(설정 수치·호버 문법·라벨/호버 캔버스 렌더러·팔레트·node-image 픽토그램·Lato). 레이아웃 = LinLog FA2 + 커뮤니티 시드 + Barnes-Hut 상시 + noverlap (1.4k 노드 ≈ 0.9s, 결정론). 구 렌더러는 `-legacy/`에 보존.
- BE: `GET /api/v1/ontology/subgraph?mandala_id=` 신설. `get_neighbors` null-relation 바인딩 크래시(42883) 수리(`::text`/`::int`). **만다라 루트가 엣지 고아인 실데이터 격차**(프로드 210k 그래프에 mandala→sector CONTAINS 0행) 대응: 섹터를 `user_mandala_levels.mandala_id`로 시드 확장 + 루트→섹터 CONTAINS를 파생 제공(실 엣지 백필 시 자동 양보).
- 검증: FE vitest 518/518 · BE 신규 회귀 0 · 실앱(실계정·실데이터) 브라우저 검증 · CI 8/8.
