## 한눈에 보기

이번 세션의 중심은 **"검색이 엉뚱한 영상을 덜 끌어오고, 콘텐츠가 없던 주제에 영상을 채운다"** 입니다.

첫째, **검색 정밀도**. 지금까지 검색어에 "강화·분석·전략" 같은 흔한 단어가 섞여, 예를 들어 "금융 투자" 만다라에 자기계발 영상 같은 엉뚱한 게 딸려 왔습니다. 이제 그런 흔한 단어를 검색에서 빼서 **핵심 주제어로만** 찾습니다(정밀도 실측 +20%p).

둘째, **콘텐츠 부재 해결**. "중등 영문법", "매일 코딩 챌린지" 같은 만다라는 **풀에 관련 영상이 거의 없어서** 검색이 좋은 결과를 못 냈습니다. 근본 원인은 영상 수집기가 "요즘 유행하는 것"만 모으고 사용자가 실제로 세운 목표 주제는 안 모았기 때문입니다. 이번에 그 목표 주제 영상들을 **직접 수집**해 채웠습니다(영문법 38개, 코딩 습관·문제해결 18개).

**정직한 범위**: 전체 검색 품질 점수(골든코호트 gc 중앙값)는 **76으로 유지**됐습니다 — 대부분 만다라가 이미 건강(73~80)했고, 이번엔 **약했던 셀만 국소적으로** 올랐습니다(금융 62→65, K8s 빈 셀 71~83, 영문법 셀 gc 92). "검색 품질 프로그램 완료"가 아니라 **"근본 원인 규명 + 1차 구현 완료"** 입니다.

## 왜 바꿨나 (측정 근거)

- 공급량을 늘려도(임베딩 +87% 커버리지) 점수가 안 올랐음 → 병목은 **양이 아니라 주제 커버리지 + 검색 정밀도**로 규명.
- daily-coding-en 셀들: cosine 최근접 후보조차 gc 45/35(게이트 60 미달) = **콘텐츠 자체가 부재** → 직접 수집이 유일 해법(측정으로 확정).
- 직접 수집 영상 품질 검증: 영문법 gc 92, 코딩 프로세스 셀 gc 62~82(전부 게이트 통과).

## 알려진 한계 / 백로그

- **daily-coding-en 기존 카드 점수(35)는 소급으로 안 바뀝니다** — 새로 수집한 콘텐츠는 신규/재생성 만다라 검색(위저드)에서 서빙됩니다. 기존 만다라 빈 셀까지 즉시 채우려면 cosine 검색 경로(아래 PR #1051)를 켜야 하는데, 지금은 꺼둔 상태(안전).
- **cosine-recruit(#1051)는 flag-OFF** — 약한 셀이 더 채워져 효과 임계에 오르면 골든코호트 검증 후 켜기.
- 남은 약셀: **26만다라(금융) 65** — 다음 세션 첫 작업으로 동일 직접수집 방식 적용 예정.
