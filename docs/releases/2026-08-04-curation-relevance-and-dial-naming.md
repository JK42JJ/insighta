# 큐레이션이 주제와 상관없는 영상을 내보내던 것을 고쳤습니다

## 한눈에 보기

"파이썬" 을 구독한 화면에 **기타 코드 연습, 메이크업 국가자격증, 스페인어 회화, lofi 플레이리스트, 다른그림찾기** 가 들어와 있었습니다. 17편 중 9편이 파이썬과 무관했고, 파이썬인 3편은 6~9년 전 영상이었습니다.

원인을 따라가 보니 한 겹이 아니었습니다.

- **적합도 판정이 한쪽 길에만 있었습니다.** 17편 중 16편이 판정을 한 번도 안 거치는 경로로 들어왔습니다.
- **검색어가 주제를 못 찾고 있었습니다.** 주제 한 단어에 "최신 / 강의 / 사례" 를 붙여 만든 라벨 4개를 검색기에 넘겼는데, "파이썬 사례" 가 성공담 쪽으로 흘러 자기계발 채널이 잡혔습니다.
- **저수지가 두 달째 비어 있었습니다.** 영상 풀 4만 편 중 최근 30일에 올라온 건 102편뿐이라, 고를 수 있는 게 옛날 영상밖에 없었습니다.

## 사용자 관점 변경점

**큐레이션**

| | 전 | 후 |
|---|---|---|
| 주제와 무관한 영상 | 17편 중 9편 | 판정을 통과한 것만 |
| 판정을 못 한 영상 | 통과시킴 | 들여보내지 않음 |
| 편성 길이 | 항상 채움 | **짧아질 수 있음** |
| 검색어 | 접미사 4개 | 진짜 하위주제 8개 |

**편성이 짧아지는 것은 의도된 결과입니다.** 무관한 영상으로 칸을 채우는 것보다 적게 보여주는 쪽을 택했습니다.

**다이얼**

- 탭 이름이 **관심 / 브리프 / 인사이트** 로 바뀌고 각각 아이콘이 붙었습니다
- 상단이 조작 버튼에서 **현재 위치와 설명을 말하는 줄** 로 바뀌었습니다
- 슬라이더 손잡이가 **자기가 있는 자리의 아이콘으로 변합니다** — 끌면 연속으로 녹아 바뀝니다
- 덱 카드 제목 오른쪽에 **북마크** 가 생겼습니다. 북마크하면 그 채널을 기억합니다
- 관심 탭 목록이 다른 탭보다 10px 낮게 시작하던 것을 맞췄습니다

## 왜 이렇게 바꿨나

**"덜 정렬된 카드가 카드 0장보다 낫다"** 는 원칙이 코드에 있었고, 그것이 이 문제를 만들었습니다. 후보가 모자라면 기준을 낮추게 되어 있었고, 낮추다 보니 스페인어 회화가 파이썬 편성에 들어왔습니다.

그 원칙을 폐기했습니다. 새 기준은 **좋은 영상을 놓치더라도 무관한 영상은 들이지 않는다** 입니다.

판정에 실패한 영상도 이제 탈락합니다. 좋은지 나쁜지 모르는 영상이고, 모르는 것은 못 들여보냅니다. 전에는 판정이 실패하면 최저점으로 통과시켰는데, 그 주석에 "LLM 장애가 주간을 비우면 안 된다" 고 적혀 있었습니다. 이제 비는 쪽이 맞습니다.

## 측정

검색어를 고친 뒤 실제로 나온 하위주제입니다.

```
파이썬 기초 문법과 데이터 타입 학습 / 함수와 모듈을 활용한 코드 구조화
파이썬으로 웹 크롤링 및 자동화 구현 / 판다스와 넘파이를 이용한 데이터 분석
장고 또는 플라스크로 웹 애플리케이션 개발 / 머신러닝과 사이킷런 기초 이해
파이썬 디버깅과 예외 처리 능력 / 실무 프로젝트로 파이썬 포트폴리오 구축
```

전과 비교하면 `파이썬` / `파이썬 최신` / `파이썬 강의` / `파이썬 사례` 였습니다.

**다만 이것만으로는 화면이 안 바뀌었습니다.** 검색어가 좋아져도 저수지가 비어 있으면 채울 것이 없기 때문입니다. 이 사실이 진단을 한 단계 더 위로 올려 주었습니다.

## 알려진 한계

- **편성이 얼마나 짧아질지 아직 모릅니다.** 판정을 실제로 돌려봐야 나오고, 0편일 수도 있습니다.
- 영상 수집이 6월 4일에 멈춰 있습니다. 재개 준비는 끝났지만 아직 정기 운영으로 돌리지 않았습니다.
- 다이얼 변경은 **폰에서만 확인 가능합니다.** 손잡이 모션, 상태줄, 목록 정렬 전부 그렇습니다.
